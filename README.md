# HH MYBEDESTEN MOCKUP

Windows ve macOS için [son sürümü indir](https://github.com/burakyaka86-coder/hhmybedestenmockup-updates/releases/latest). 3.8.0 ve üzeri sürümler güncellemeleri uygulama içinden alabilir.

Windows için kurulum dosyasını (Setup) veya taşınabilir EXE'yi (Portable) seçin. Mac için işlemcinize uygun arm64 (Apple Silicon) veya x64 (Intel) ZIP'i açıp uygulamayı yazılabilir bir Applications klasörüne taşıyın.

Windows paketleri Authenticode imzası taşımaz. Mac paketleri ad hoc imzalıdır. Apple Developer ID ve noter onayı olmadığından macOS internetten indirilen uygulamanın açılmasına izin vermeyebilir.
